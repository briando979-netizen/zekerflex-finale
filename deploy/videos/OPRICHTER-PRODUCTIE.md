# ZekerFlex Oprichter-Video: Productieguide

**Datum gemaakt:** 28 nov 2026  
**Duur:** 3 minuten (180 seconden)  
**Platform:** YouTube (hoofd), LinkedIn, Instagram Reels, TikTok  
**Script-versie:** 1.0  

---

## Overzicht

Dit is een **founder pitch video**: wie is ZekerFlex, wat doen ze, waarom nu, wat je moet doen.

**Toon:** Casual, echt, geen BS. Nederlands, authentieke stem. Eigenaar spreekt zelf (of verteller met gevoel, maar REËEL).

---

---

## Visuele Stijl

### Kleuren & Betekenis
- **Rood:** Chaos, probleem  
- **Groen:** Vertrouwen, oplossing  
- **Blauw/Paars:** Hoogtepunten, tech  

### Design-principes
1. **Schoon.** Geen geklaag, geen overbodige animaties.
2. **Data-driven.** 500K = echt getal. Timing = echt resultaat.
3. **Human.** Gezichten, echte werkers, echte kantoor.
4. **Geen corporate.** Jeans & T-shirt, niet pak. Laagdrempelig kantoor.

## Production Checklist

### Voiceoverrecording
- [ ] Script goedgekeurd
- [ ] Eigenaar (of verteller) geoefend
- [ ] Studio-booking of home-recording setup
- [ ] Microfoon: Duidelijk, geen achtergrond
- [ ] Multiple takes per sectie
- [ ] Final mix: Genormaliseerd geluid

### B-Roll Collectie
- [ ] App-screenshots (van live build)
- [ ] Job-board screenshots (verpixel ze)
- [ ] Animaties: ID-scan, matching, grafiek
- [ ] Real footage: Kantoor, werkers, bedrijf
- [ ] Stock footage (Pexels, Unsplash, Epidemic Stock):
  - Chaos-scène
  - Kantoor-scène
  - Montage van tevreden mensen

### Muziek & Sound Effects
- [ ] Muziek-track: Modern, urgent, hopeful (Dutch indie / tech vibe)
- [ ] SFX: Vinkje-geluid, transactie-ping, impact-slot
- [ ] Stille momenten: Purposeful, niet weg

### Editing
- [ ] Voiceover gesneden op timing
- [ ] B-roll synced met voiceover
- [ ] Transitions: Strak, niet overdreven
- [ ] Color grading: Consistent, filmisch
- [ ] Motion: Smooth, geen jerky bewegingen
- [ ] Text overlays: Klaar, groot, leesbaar
- [ ] Finale: Logo + tagline met geluidscape

### Review & Tweaks
- [ ] Eigenaar review
- [ ] Timing check (totaal 180s)
- [ ] Audio mix review
- [ ] Visual coherence check
- [ ] Final export (ProRes, 4K indien mogelijk)

### Upload & Distribution
- [ ] YouTube: Title, description, tags, transcript
- [ ] LinkedIn: Edit voor professionals
- [ ] Instagram Reels: Vertical format (9:16)
- [ ] TikTok: Caption, tags
- [ ] Website: Embed op homepage

## Muziek-Voorstel

**Mood:** Modern, urgent, hopeful. Dutch indie of tech startup vibe. NOT corporate.

**BPM:** ~120  

**Sources:**
- Epidemic Sound
- Artlist
- YouTube Audio Library
- Local Dutch indie artiest (indie vertrouwen > generic)

**Track structure:**
1. **Hook (0:00–0:15):** Intro, urgent, grab attention
2. **Problem (0:15–0:45):** Tension, building
3. **Solution (0:45–2:00):** Relief, energy up, hopeful
4. **Why Now (2:00–2:30):** Inspirational, calm
5. **CTA (2:30–3:00):** Climax, release

---

## Tips voor Oprichter (mocht hij spreken)

1. **Authentiek.** Dit is geen marketing-spiel, dit is real. Laat dat door.
2. **Geen nerveus lachen.** Dit is serius. Je weet wat je zegt.
3. **Pauzes zijn je vrienden.** Laat die woorden landen.
4. **Energie.** Hook en CTA: volume omhoog, sneller. Problem → Solution shift voelbaar.
5. **In eerste take:** Krijg je energie eruit, daarna edit.
6. **Camera:** Recht tegen de lens, niet opzij. Direct.

## Distribution Strategy

### YouTube (Hoofd-kanaal)
- Full 3-minuut video
- SEO-tags: flexwerk, ZekerFlex, werkzoeken, recruiting
- Transcript: Voor accessibility + SEO
- Call-out: Link naar app en website in description
- Pinned comment: Download link + website

### LinkedIn (B2B)
- 90–120 seconden excerpt (Problem + Solution)
- Native upload (beter bereik)
- Text: Recruiter-toon, HR-manager-toon
- CTA: Gratis maand voor bedrijven

### Instagram Reels (Werkers)
- Vertical 9:16 format
- 60 seconden max
- Captions: Ondertitels voor geluid uit
- CTA: Link naar app-download
- Reels-hashtags: #flexwerk #bijbaan #werkzoeken

### TikTok (Jonge werkers)
- Vertical, 60s max
- Trending sound (optioneel) of custom
- Duet/Stitch-vriendelijk
- CTA: Link in bio

### Website (Homepage)
- Embedded YouTube player
- "Meet the Founder" sectie
- Direct app-download buttons eronder

---

## Notes

- **Authenticity > perfectie.** Een rauwe, echte video wint van een glimmend corporate-ding.
- **Data is overtuigend.** 500K werkers, 24h matching = real, niet hype.
- **Nederlands.** Deze video is VOOR Nederlandse markt. Geen Engels, tenzij later een Engelse versie.
- **Reusable clips.** De Solution-clips kunnen later in ad-campaigns/landing-pages gebruikt worden.
